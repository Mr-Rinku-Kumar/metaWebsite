How It Works

Simple integration in 3 steps

1

Install SDK

Add our SDK to your Android or iOS project via Gradle/CocoaPods. Initialize with your API key.

2

Capture & Enroll

Use our built-in camera interface to capture faces and create encrypted templates stored locally.

3

Verify & Authenticate

Match faces against stored templates instantly—all processing happens on-device for maximum speed.
